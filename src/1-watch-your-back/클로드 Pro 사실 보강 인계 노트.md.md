## 2. 클로드 Pro에서 진행할 사실 보강 체크리스트

### [보강 1] GitHub 레포지토리 공개 전환 및 링크 검증 (1-3절)
- **위치**: `1-3. 개발 환경 · 링크` 하단
- **확인 사항**:
  - `https://github.com/KooHoo-Dev/3rd-2D-Project-pinkshield` 레포지토리가 **Public**으로 전환되었는지 확인
  - 비로그인/시크릿 창에서 링크 접속 및 이미지/영상 경로가 깨지지 않는지 점검

### [보강 2] 7-2 B 추격 BGM 카운터 미초기화 버그의 정확한 원인 규명 (7-2절)
- **위치**: `7-2. 트러블슈팅 > B. 추격 음악이 처음 한 번만 나오는 문제`
- **확인 사항**:
  - 레포지토리의 `SoundManager.cs`와 `GameSceneInitializer.cs` 실제 코드를 대조하여, `ResetCombatMusicState()`를 호출했음에도 왜 재시도 후 추격 BGM이 나오지 않았는지 정확한 코드 원인을 확인 (예: 실행 순서 문제, BGM 오디오 소스 상태 미복구, 또는 `SwitchBgm` 내부 조건문 등)
  - 원인이 명확해지면 `(추정)` 표기를 제거하고 실제 코드 근거로 서술 보완

### [보강 3] AI 코드 리뷰 검증 내역 및 시연/디버그 자료 확인 (6-1절)
- **위치**: `6-1. AI 코드 리뷰로 다시 본 내 코드` 하단
- **확인 사항**:
  - 회피 각도(#1), 대기 시간(#2) 외에 추가 검증 장면(지뢰 넉백 판정 확인, 시야 박스 시각화 테스트 등)을 본문에 포함할지 여부 결정 및 필요 시 이미지/설명 보강
  - 본문 내 이미지 경로(`images/...`)와 실제 폴더 내 파일명 일치 여부 확인

### [보강 4] 기존 AI 요약 문단의 본인 어투 및 사실 일치 검토 (1-2절, 2-2절, 3-3절, 4-1절, 5장)
- **위치**: 각 섹션 내 `[사실 보강 예정: ...]` 태그 표시 구간
- **확인 사항**:
  - `1-2` 문제 요약표, `2-2` 코어 루프 설명, `3-3` 박스 설계 배경, `4-1` 역추론 비교표, `5장` 트레이드오프 표의 문장이 개발 당시 실제 의도와 어긋남이 없는지 사용자 확인 후 어투 다듬기
