## 2. 보강이 필요한 항목 (9곳)

### A. 프로젝트 링크 및 본인 문체 확인
1. **1-3 GitHub 공개 여부**
   - 현재: `강사님 추후 공개 예정`
   - 보강 포인트: 현재 GitHub 저장소가 공개(Public)로 전환되었는지 확인 후 URL 연결 또는 `비공개 (학원 과제 저장소)` 등으로 확정
2. **2-2 코어 루프 설명 문단**
   - 현재: *"이 반복이 1-2에서 의도한 경험을 만듭니다..."* 문단
   - 보강 포인트: 이전 Claude 초안 문장이므로 작성자 본인의 의도·말투와 어긋나는 부분이 없는지 최종 확인

### B. AI 협업 및 스크립트 실제 수치·검증 과정 (핵심 보강 구간)
3. **3-1 & AI 협업 — 쿠션 / 가속 판자 스크립트 동작 및 수치**
   - 현재: `수치를 고쳐 썼습니다 (공을 튀어 오르게 하는 힘 / 고양이 높이 값)`
   - 보강 포인트:
     - 쿠션 스크립트(`Cushion` 등)에서 공을 튀어 오르게 하는 방식(`AddForce`인지 `velocity` 직접 대입인지)과 조정한 힘의 구체적 수치
     - 가속 판자 스크립트(`BoostPad` 등)의 가속 방식 및 Inspector 설정값
     - 고양이(`CatController.cs`)의 바닥 높이($y$) 위치 보정값
4. **AI 협업 — 사용한 AI 도구 및 검증·트러블슈팅 사례**
   - 보강 포인트:
     - 사용한 AI 도구명 명시 (예: ChatGPT, Claude 등)
     - **잘 된 것**: AI가 작성한 함정 스크립트가 의도대로 작동하는지 확인한 구체적 방법 (예: 시연 영상·테스트 씬에서 공을 직접 굴려 반발 각도·고양이 추적 반경 테스트 등)
     - **안 된 것**: 함정 설명이 부족해 AI 코드에 어떤 버그/오동작이 있었고, 어떻게 수정했는지 1가지 구체적 사례 추가 (예: 가속 판자 방향 벡터 오류, 고양이 NavMesh 이탈, 쿠션 연속 충돌 등)

### C. 레벨 디자인 규칙 대조
5. **5-2 아쉬운 점 ② — 소개 코스(창고방) vs 거실 첫 등장 함정**
   - 현재: *"창고방을 튜토리얼(소개 코스)로 두었지만, 거실에 새로 등장하는 함정이 있었습니다."*
   - 보강 포인트: 창고방(소개 코스)에 배치된 함정/기믹과 거실(응용·심화 코스)에서 예고 없이 처음 등장한 함정(예: 고양이, 가속 판자 등)이 각각 무엇인지 구체적으로 명시
